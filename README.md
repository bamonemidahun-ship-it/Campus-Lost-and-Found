
#  Campus Lost & Found Portal

A web-based system that helps students and staff report lost items and upload found items within a university campus.
The Campus Lost & Found Portal is designed to digitize the traditional lost and found system. It allows users to:

- Report lost items
- Upload found items
- Search for items
- View item details
- Manage user sessions securely

##Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- PHP

### Database
- MySQL

### Server
- XAMPP (Apache + MySQL)

---

##  Features

###  User Features
- User Registration & Login
- Session-based authentication
- Report Lost Items
- Upload Found Items (with image)
- Search items by title/location
- View item details
- Responsive design (mobile friendly)
- Dark/Light theme toggle



##  Setup Instructions (Run Locally)

### Step 1: Install XAMPP
Download and install XAMPP.

### Step 2: Move Project
Copy the project folder to: C:\xampp\htdocs\

### Step 3: Start Server
- Open XAMPP Control Panel
- Start:
  - Apache
  - MySQL
